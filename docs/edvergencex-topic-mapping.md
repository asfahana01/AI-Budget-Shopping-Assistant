| JSON handling | Zod-validated request payloads and JSON catalog processing | `backend/src/middleware/validate.js`, `backend/src/services/dataProcessing.js` | Product and tool APIs | Implemented | Catalog JSON remains the offline source of truth. |

| Context engineering | Verified product and combination payloads for recommendation explanations | `backend/src/services/contextBuilder.js`, `backend/src/services/llm.js` | `POST /api/recommend` | Implemented | The model does not own pricing or totals. |
| Multimodal AI | Product image analysis with conservative unknown values | `backend/src/services/vision.js`, `backend/src/services/llm.js` | `POST /api/analyze-image` | Implemented | Uses an optional OpenAI-compatible vision API; no-key behavior is deterministic. |
| Basic RAG | Policy/fact documents, chunking, embeddings, similarity retrieval, citations | `backend/src/services/rag/` | `POST /api/knowledge/query` | Implemented | Retailer terms absent from the repo are reported as unavailable. |
| Adaptive RAG | Deterministic route selection, one bounded rewrite, retrieval verification | `backend/src/services/queryRouter.js`, `backend/src/services/rag/adaptiveRag.js` | `POST /api/chat` | Implemented | Classification is heuristic; unclear wording receives clarification. |
| Graph RAG | Catalog product/category/feature graph with relationship expansion | `backend/src/services/graph/` | `POST /api/graph/query` | Implemented | Graph edges reflect catalog fields and do not imply undocumented compatibility. |
| Few-shot prompting | Concrete shopping examples for requirement extraction and normalization | `backend/src/services/prompts.js`, `backend/src/services/requirementExtractor.js`, `backend/src/services/llm.js` | LLM extraction path in `POST /api/chat` | Implemented | Prompt examples are used only as guidance for normalization and never override backend budget or catalog facts. |
| Model comparison | Safe model-by-model evaluation using a server-side allowlist | `backend/src/services/modelEvaluation.js`, `backend/src/routes/api.js`, `backend/src/config.js` | `POST /api/evaluate/models` | Implemented | It is for evaluation only; it cannot select catalog products or edit totals. |
| Public API GET and JSON handling | Optional external JSON enrichment with timeout, validation, dedupe, and safe fallback | `backend/src/services/externalProductApi.js`, `backend/src/routes/api.js` | `GET /api/external-products` | Implemented | External data is optional and cannot replace the verified local catalog. |
| MCP protocol integration | Official MCP SDK server with stdio transport and the validated shopping tools | `backend/src/mcp/protocolServer.js`, `backend/src/mcp/start.js`, `backend/src/mcp/server.js` | `npm run mcp --prefix backend` | Implemented when the environment supports the official MCP SDK | The internal HTTP adapter remains the supported app surface; protocol transport is separate. |
| Python data-handling compatibility | Optional Python catalog analysis for educational parity with JavaScript logic | `tools/python_catalog_analysis.py`, `tools/README.md` | `python tools/python_catalog_analysis.py` | Implemented as optional educational example | Not part of the production runtime or credentials flow. |

| Image generation | Optional generated board from verified product categories and known colors | `backend/src/services/imageGeneration.js`, `backend/src/routes/api.js` | `POST /api/generate-shopping-preview`, preview intent in chat | Implemented | Requires a compatible image-generation API; generated images are illustrative, not product photos. |
| Session memory | In-memory session map with optional MongoDB-backed sessions | `backend/src/services/sessionStore.js`, `backend/src/models/ChatSession.js` | `POST /api/chat` | Implemented | Conversation history is bounded to the latest 20 messages. |
